# Changelog

Versions follow [semantic versioning](https://semver.org). Each release is tagged `vX.Y.Z`.

## 1.0.0 — 2026-11-05

First public release: the 21-episode campaign of Capone (1997) is playable on the original game's files.
Licensed under GPL-3.0-or-later.

- Main menu, mission briefings, win and defeat screens, campaign progress.
- Maps built from the original city blocks; fog of war, minimap, the original cursors, sounds and voices.
- Every gangster type with the original stats and pictures, the original orders and combat; Cadillacs carry four
  gangsters; the Hit man hides while he holds his fire; the Thief steals cash.
- Extortion, income and market share, collectors, business conversion, selling, repair, training centres.
- Bribes, favour points and the authorities' services: police raids, demolition, blackouts, FBI visits and
  informers, lawyers, legalisation.
- Police arrests; unpaid gangsters desert.
- Computer players with the original's strategies.
- Victory conditions, elimination, last player standing; money transfer, alliances and statistics windows.
- Quick save and load (F5 / F8), pause key, resizable window.
- Optional changes in `game.cfg`: A* path search, cars kept off forecourts, computer players' brownouts, more
  businesses on the map. Unit, business and rule numbers can be edited in `Data/*.json`.
- Windows package: the game asks for the Capone folder on the first start; no Godot or .NET install needed.

Not included: the network game, the main menu's Settings and Developers screens.

CAPONE REBORN
=============
Version {VERSION}


A fan remake of Capone (1997), the gangster strategy game, made with Godot and C#.
It plays on the files of the original game, which you need to own: this package contains none of them.

Starting
--------
1. Unpack this folder anywhere.
2. Run CaponeReborn.exe.
3. On the first start, choose your Capone folder (the one with Capone.EXE and Chicago.tile).
   The choice is saved to original.cfg next to CaponeReborn.exe; edit or delete that file to change it.
   If CaponeReborn.exe is in the Capone folder itself, it needs no setup.

Keys
----
Left click / drag   select          Right click   go, attack, extort
Arrows, screen edge scroll          Mouse wheel   zoom
+ / -               game speed      Pause         pause
F5 / F8             quick save / quick load
H                   show your headquarters
G A E D O           Go, Attack, Extort, Disguise, Patrol
T P M B S L K C I   hire Thug, Pistol man, Thompson man, Terrorist, Sniper, Shotgun man, Hit man, Cadillac, Thief
Ctrl+digit          store a group; digit selects it, Shift+digit selects and shows it
Ctrl+G / A / I      money, alliances, statistics

Files you can edit (restart the game after a change)
----------------------------------------------------
game.cfg                 the remake's options, explained inside (each says what the original did)
Data/unit_stats.json     unit numbers: cost, hit points, damage, range, speed...
Data/businesses.json     businesses: prices, incomes, hit points, build times
Data/rules.json          other rule numbers
The Data files hold the original game's values. Delete one to go back to the original values.

Campaign progress and the quick save are kept in %APPDATA%\Godot\app_userdata\CaponeSharp\
(campaign.cfg, quicksave.json). Delete campaign.cfg to start the campaign again.

If the game doesn't start, run CaponeReborn.console.exe to see its messages.

CAPONE REBORN (по-русски)
=========================

Любительский ремейк стратегии Capone (1997) на Godot и C#.
Ремейк работает на файлах оригинальной игры, которая должна у вас быть: в этом архиве их нет.

Запуск
------
1. Распакуйте папку куда угодно.
2. Запустите CaponeReborn.exe.
3. При первом запуске укажите папку игры Capone (ту, где лежат Capone.EXE и Chicago.tile).
   Выбор сохраняется в original.cfg рядом с CaponeReborn.exe; чтобы сменить папку, исправьте или удалите этот файл.
   Если CaponeReborn.exe лежит в самой папке Capone, ничего указывать не нужно.

Стрелки, край экрана  прокрутка       Колесо мыши    масштаб
+ / -                 скорость игры   Pause          пауза
F5 / F8               быстрое сохранение / загрузка
H                     показать штаб
G A E D O             Идти, Атаковать, Рэкет, Маскировка, Патруль
T P M B S L K C I     нанять вышибалу, стрелка, гробовщика, террориста, снайпера, налётчика, киллера, кадиллак, вора
Ctrl+цифра            запомнить группу; цифра выбирает её, Shift+цифра выбирает и показывает
Ctrl+G / A / I        деньги, союзы, статистика

Файлы, которые можно править (после правки перезапустите игру)
--------------------------------------------------------------
game.cfg                 настройки ремейка, с пояснениями внутри (для каждой сказано, как было в оригинале)
Data/unit_stats.json     числа бойцов: цена, здоровье, урон, дальность, скорость...
Data/businesses.json     бизнесы: цены, доходы, прочность, время постройки
Data/rules.json          прочие числа правил
В файлах Data — значения оригинальной игры. Удалите файл, чтобы вернуть оригинальные значения.

Прохождение кампании и быстрое сохранение лежат в %APPDATA%\Godot\app_userdata\CaponeSharp\
(campaign.cfg, quicksave.json). Удалите campaign.cfg, чтобы начать кампанию заново.

Если игра не запускается, запустите CaponeReborn.console.exe — он покажет сообщения игры.
